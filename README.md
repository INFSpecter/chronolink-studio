# CHRONOLINK STUDIO v1.1.0
**Powered by `chronolink` • Created by `INF_Specter`**

## Highlights
- **Animated Terminal Intro Video (`[I]` to replay):** Full-color ASCII startup animation introducing **CHRONOLINK STUDIO**.
- **10,800-Case Database:** Precomputed lookup matrix across 24 hours, 15 minute brackets, and 10 major timezones running on `chronolink`.
- **Zero-Flicker Centered HD Christmas & Neon LEDs (`[X]` to switch themes):** Smooth 24-bit TrueColor chasing LEDs.
- **Built-in One-Key Self-Updater (`[U]`):** Allows both `INF_Specter` and any user who downloads the release to update to the latest version directly from GitHub.
- **Conversational AI Advisor (`[A]`), World Clocks (`[W]`), Diagnostics (`[D]`), and Persistent Worked/Failed Stats (`[Y]`/`[N]`/`[L]`).**

## How Anyone Can Install & Update
1. Download and unzip `Chronolink_Studio_v1.1.0_INF_Specter.zip`.
2. Double-click **`Chronolink Studio.command`** on macOS.
3. Press **`U`** anytime inside the app to automatically download and apply future updates published by **INF_Specter**.
